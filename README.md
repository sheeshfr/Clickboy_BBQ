## How to Use

1. **Boot it up**
2. **Set the key you want**
3. **Change the interval** (`50ms` = 20 CPS / clicks per sec)
4. **Choose Toggle or Hold**:
   - **Toggle**: An on/off switch.
   - **Hold**: Active while the button is pressed, off when released.
